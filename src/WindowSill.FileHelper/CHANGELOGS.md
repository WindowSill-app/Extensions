# 0.9.29

- Initial release.
- Added conversion tools for documents, spreadsheets and presentations.
- Added PDF tools to merge, split, extract and compress files, save pages as images, and add or remove passwords.
- Added ZIP archive inspection without extraction.
- Added text tools to re-encode files as UTF-8 or UTF-16 and switch between Windows (CRLF) and Unix (LF) line endings.
